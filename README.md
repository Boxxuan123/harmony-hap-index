## 收录规则

系统根据配置中的搜索词发现候选仓库，然后读取这些仓库的 Releases 并筛选文件名以 `.hap` 结尾的附件。GitHub 搜索无法保证覆盖所有公开仓库，因此欢迎通过 Pull Request 提交遗漏的仓库；可以把仓库加入 `seed_repositories`。

请在使用安装包前自行核对项目源码、许可证、发布者和文件来源。索引页面保留原始仓库与 Release 链接。
